# Guía Local — Android (prototipo)
La aplicación Android abre https://www.guialocal.ar/ mediante Android WebView. Mantiene almacenamiento local y cookies, muestra páginas de Firebase integradas en Jimdo y solicita ubicación mediante permisos Android. La sesión puede caducar según las credenciales del servidor.
APK debug: solo para prueba, no distribución pública.
